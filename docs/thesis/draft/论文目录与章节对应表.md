## 二、与旧材料（`docs/thesis/`）的差异说明

`docs/thesis/` 下的 11 份材料写于 2026-10-03，描述的是**原生界面迁移之前**的系统状态。本初稿未直接拼接这些材料，凡与当前实现不符的论述均已改写。主要差异如下：

| 项 | 旧材料（2026-10-03） | 当前实现（本次核实） |
|---|---|---|
| 桌面界面 | React 前端 + Tauri/WebView2 外壳 | Qt 6 / QML 原生界面（`desktop-native/`） |
| 数据库表数 | 22 张 | **34 张** |
| 迁移 | 称"仓库中无迁移文件" | **9 个版本化迁移**（1366 行），启动由 `alembic upgrade head` 建库 |
| 建表方式 | `Base.metadata.create_all` | 迁移为唯一结构来源；`create_all` 仅用于测试 |
| 模型接入 | 称"未接入云端大模型" | 已接入云端提供方，并有连接测试与五档状态 |
| 测试规模 | 75 个断言 | **1377 个用例**（1367 通过） |
| 接口规模 | 49 路径 / 65 操作 | **123 路径 / 155 操作** |
| 工具数 | 42 或 11（两处不一致） | 业务 11 + 计算机 44 |
| 论文章节数 | 声明"共分十章" | 本文共八章 |

> 说明：`docs/thesis/10-总结与展望.md` 第 10.4.6 节称"仓库中无 README、根目录无 .gitignore、当前目录不是 git 仓库"，与仓库实际情况直接矛盾，该段内容未予采用。
