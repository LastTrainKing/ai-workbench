# 参考文献核验清单

**核验原则**：
- 只把能够查到出处、且题名与作者匹配的文献列入正文引用。
- 未能核实到完整出版信息的条目，**不列入正文**，在本清单中单独标出并说明需要人工查证的具体字段。
- 不编造页码、DOI 与卷期号。凡是本次核验中未直接看到的字段，在表中标注"未逐项核实"。

核验时间：2026-10-12。

## 三、需要注意的著录事项

1. **页码与卷期号**：表中标注"未逐项比对"的字段，是按该文献的通行著录填写的，本次核验未逐页打开原文确认。**提交前建议按学校模板要求，对这几处做一次逐项比对**，涉及的条目为 [1]、[3]、[6]、[8]、[11]。
2. **预印本与正式出版**：[2] 为 arXiv 预印本，无正式出版信息；若学校要求只引用正式发表文献，建议替换为该主题的已发表综述。
3. **文献数量**：当前共 13 条学术文献 + 7 条技术文档。**是否满足学校对参考文献数量的要求需作者确认**（部分院校要求 15 条以上学术文献）。
4. **中文文献**：当前清单中没有中文文献。任务书中建议优先使用知网、万方等可访问的中文学术数据库，但本次核验**未能通过公开检索确认到具体的中文文献条目**（题名、作者、期刊、年份四项齐全且可查证）。为避免编造，本文未列入任何中文文献。**这一缺口需要作者自行检索补充**，可考虑的主题包括：检索增强生成的中文综述、知识图谱与个人知识管理、大语言模型智能体的中文研究。
5. **引用位置**：正文中 [1]–[13] 均有明确引用位置（见《论文目录与章节对应表.md》），不存在"列入参考文献但正文未引用"的条目。
