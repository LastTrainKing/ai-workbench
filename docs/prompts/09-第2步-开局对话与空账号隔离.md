### 1.2 上一轮修掉的两个缺陷(别回退)

**① `installer\ai-workbench.nsi` 的 `IfSilent +2 0` 跳过了守卫**

NSIS 里 `IfSilent jump_if_silent jump_if_not_silent` 取**第一个标签**。`+2` 从下一条指令数,所以静默路径**连 `Abort` 一起跳过了** —— `/S` 卸载时那个"程序正在运行就拒绝"的守卫完全失效,会把程序从正在运行的副本底下删掉。

现在是 `IfSilent 0 +2`:`0` 落到 MessageBox,`+2` 跳过 MessageBox 落在 `Abort`,两种模式下守卫都成立。

**② `scripts\verify_installer.py` 的卸载验证有竞态**

`/S` 返回时删除还没完,而卸载段的顺序是**先删快捷方式、后删目录**。原来只等目录消失 → 快捷方式那两条断言跑在缝隙里,给一次**已经成功**的卸载报了两条失败。现在同时轮询目录和两个快捷方式,90 秒超时。

### 1.3 ⚠️ 一个必须记住的坑(已写进提交信息)

**`installer\ai-workbench.nsi` 带 UTF-8 BOM,而 makensis 靠 BOM 才能读那些中文。**

上一轮用编辑器改它时**把 BOM 弄丢了**,构建立刻失败:

```
Bad text encoding: installer\ai-workbench.nsi:65
Error in script ... on line 65 -- aborting creation process
```

第 65 行是欢迎页那段中文。**改这个文件必须用保留 BOM 的工具**;改完确认前三字节是 `EF BB BF`。

**本项目在编码上已踩过三次,三条规则并列记住:**

| 文件 | 规则 |
|---|---|
| `.bat` | 必须**纯 ASCII**(cmd.exe 按 ANSI 读,非 ASCII 会让注释被当命令执行) |
| `.ps1` | 含非 ASCII 必须带 **UTF-8 BOM** |
| `.nsi` | 含中文必须带 **UTF-8 BOM** |
